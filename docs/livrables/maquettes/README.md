# Maquettes UI/UX — INFIRMO MVP

Les maquettes UI/UX du MVP INFIRMO sont réalisées dans Figma.

## Accès au fichier Figma

Lien vers les maquettes :

```text
https://www.figma.com/design/b3BFPg8LirxbxDmnFB7xNo/Infirmo?node-id=178-1462&t=o43eLBvPcJhb9X3z-1
```

Le fichier Figma constitue la référence visuelle du projet pour la conception de l’application mobile. Il centralise les principaux écrans et parcours utilisateurs du MVP, notamment l’authentification, les profils, la recherche de remplacements, les offres, les candidatures, la messagerie, les transmissions et les fonctionnalités liées à la transcription vocale.

## Utilisation

Les maquettes servent de support à la validation des parcours utilisateurs, à l’organisation de l’interface et au développement progressif de l’application mobile Flutter.
